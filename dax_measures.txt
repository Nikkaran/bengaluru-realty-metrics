DAX MEASURES — BENGALURU HOUSE PRICE INTELLIGENCE
=================================================
Power BI Desktop / Fabric semantic model
Fact table:  'Bengaluru Housing'      (cleaned_bengaluru_housing.csv)
Measures are created in a dedicated measures table where possible.

IMPORTANT MODEL SET-UP
----------------------
1. Load cleaned_bengaluru_housing.csv and rename the query/table to
   exactly: Bengaluru Housing
2. Load feature_importances.csv as: Feature Importances (Page 2 only; no
   relationship is required).
3. Create the disconnected Sq.Ft parameter table below. It must have NO
   relationship to 'Bengaluru Housing'.
4. Column names used here are generated by data_prep.py:
   price_lakh, predicted_price_lakh, total_sqft, price_per_sqft,
   location, bhk, bath, balcony, property_id.
5. Set the data type of price_lakh and predicted_price_lakh to Decimal
   Number or Fixed Decimal Number. Do not use Whole Number.

--------------------------------------------------------------------------------
1) CREATE THE DISCONNECTED WHAT-IF TABLE
--------------------------------------------------------------------------------
Recommended: Modeling > New parameter > Numeric range
    Name ................. SqFt Parameter
    Data type ............ Decimal number
    Minimum .............. 300
    Maximum .............. 5000
    Increment ............ 50
    Default .............. 1000
    Add slicer to page ... Yes

After creation:
    * Rename the generated value column to exactly: Target SqFt
    * Rename or hide the auto-generated measure. This file uses [Target Sq.Ft].
    * Confirm the table is NOT related to 'Bengaluru Housing'.

Equivalent calculated table (manual alternative):
SqFt Parameter =
SELECTCOLUMNS (
    GENERATESERIES ( 300, 5000, 50 ),
    "Target SqFt", [Value]
)
Then add a single-value numeric slicer on SqFt Parameter[Target SqFt].

--------------------------------------------------------------------------------
2) CORE KPI MEASURES
--------------------------------------------------------------------------------

Total Properties =
COUNTROWS ( 'Bengaluru Housing' )
// Format: Whole number, thousands separator: #,##0

Average Price =
AVERAGE ( 'Bengaluru Housing'[price_lakh] )
// Format: ₹#,0.00 " L"
// Unit: INR lakh (the source target is expressed in lakhs).

Average Price per Sq.Ft =
DIVIDE (
    SUMX (
        'Bengaluru Housing',
        'Bengaluru Housing'[price_lakh] * 100000
    ),
    SUM ( 'Bengaluru Housing'[total_sqft] )
)
// Format: ₹#,0
// This is a transaction-value-weighted rate, not an average of row ratios.
// That makes large properties contribute proportionally to market value.

--------------------------------------------------------------------------------
3) WHAT-IF / SIMULATOR MEASURES
--------------------------------------------------------------------------------

Target Sq.Ft =
SELECTEDVALUE ( 'SqFt Parameter'[Target SqFt], 1000 )
// Single-select slicer. The fallback of 1000 keeps the card stable if the
// slicer is cleared. Format: #,##0 " sq.ft."

Average Predicted Price per Sq.Ft =
DIVIDE (
    SUMX (
        'Bengaluru Housing',
        'Bengaluru Housing'[predicted_price_lakh] * 100000
    ),
    SUM ( 'Bengaluru Housing'[total_sqft] )
)
// Format: ₹#,0
// OOF model estimate, weighted by area. Uses the BHK/location slicer context.

Citywide Predicted Price per Sq.Ft =
CALCULATE (
    [Average Predicted Price per Sq.Ft],
    REMOVEFILTERS ( 'Bengaluru Housing' )
)
// Format: ₹#,0
// Used only as a stability fallback when a segment is too small.

Benchmark Price per Sq.Ft Used =
VAR SegmentRate = [Average Predicted Price per Sq.Ft]
VAR SegmentCount = [Total Properties]
VAR CitywideRate = [Citywide Predicted Price per Sq.Ft]
VAR HasEnoughComparables = SegmentCount >= 5 && NOT ISBLANK ( SegmentRate )
RETURN
    IF ( HasEnoughComparables, SegmentRate, CitywideRate )
// Format: ₹#,0
// Transparent guardrail: fewer than five selected listings falls back to
// the citywide model benchmark.

Estimate Basis =
VAR SegmentCount = [Total Properties]
VAR SegmentRate = [Average Predicted Price per Sq.Ft]
RETURN
    SWITCH (
        TRUE (),
        SegmentCount >= 5 && NOT ISBLANK ( SegmentRate ),
            "Segment benchmark (" & FORMAT ( SegmentCount, "#,0" ) & " listings)",
        "Citywide fallback (low sample)"
    )
// Format: Text. Use on the simulator page as a trust/quality label.

Estimated Price (Lakh) =
VAR TargetArea = [Target Sq.Ft]
VAR BenchmarkRate = [Benchmark Price per Sq.Ft Used]
VAR RawEstimate = DIVIDE ( TargetArea * BenchmarkRate, 100000 )
RETURN
    IF (
        NOT ISBLANK ( TargetArea )
            && NOT ISBLANK ( BenchmarkRate )
            && TargetArea > 0,
        ROUND ( RawEstimate, 2 ),
        BLANK ()
    )
// Format: ₹#,0.00 " L"
// THE WHAT-IF OUTPUT: disconnected target area × selected-segment model
// benchmark. It is an indicative estimate, not a formal valuation.

Estimated Price (Cr) =
DIVIDE ( [Estimated Price (Lakh)], 100 )
// Format: ₹#,0.00 " Cr"

Scenario Summary =
VAR TargetArea = FORMAT ( [Target Sq.Ft], "#,##0" )
VAR BhkLabel =
    IF (
        ISFILTERED ( 'Bengaluru Housing'[bhk] ),
        IF (
            HASONEVALUE ( 'Bengaluru Housing'[bhk] ),
            FORMAT ( SELECTEDVALUE ( 'Bengaluru Housing'[bhk] ), "0" ) & " BHK",
            "Multiple BHK"
        ),
        "All BHK"
    )
VAR LocationLabel =
    IF (
        ISFILTERED ( 'Bengaluru Housing'[location] ),
        IF (
            HASONEVALUE ( 'Bengaluru Housing'[location] ),
            SELECTEDVALUE ( 'Bengaluru Housing'[location] ),
            "Multiple locations"
        ),
        "All locations"
    )
RETURN
    TargetArea & " sq.ft.  |  " & BhkLabel & "  |  " & LocationLabel
// Format: Text. Place under the Estimated Price card.

Comparable Listings =
[Total Properties]
// Alias used on the simulator page for clarity. Format: #,##0.

--------------------------------------------------------------------------------
4) OPTIONAL DETAIL-TABLE MEASURE
--------------------------------------------------------------------------------

Predicted vs Asking Gap % =
VAR Asking = SELECTEDVALUE ( 'Bengaluru Housing'[price_lakh] )
VAR Predicted = SELECTEDVALUE ( 'Bengaluru Housing'[predicted_price_lakh] )
RETURN
    DIVIDE ( Predicted - Asking, Asking )
// Format: 0.0 %
// Use ONLY in a row-level table that includes property_id (unique key),
// otherwise a multi-row filter context returns BLANK.

--------------------------------------------------------------------------------
6) SANITY-CHECK LOGIC
--------------------------------------------------------------------------------
* Avg. price per sq.ft. is weighted: total value ÷ total area.
* The target-area slider has no relationship to the fact table.
* BHK and Location slicers filter the fact table and therefore the segment
  benchmark.
* Fewer than five selected listings triggers the citywide fallback.
* Expected reference-run outputs on the Kaggle train.csv snapshot:
      Total Properties ............. 12,685
      Average Price ................ ~97.33 lakh
      Average Price per Sq.Ft ...... ~6,428 INR
* Values will move slightly if the cleaning thresholds in data_prep.py
  are changed.
