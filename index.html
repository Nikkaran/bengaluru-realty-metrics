Bengaluru Realty Metrics

Real Estate Market Intelligence & Predictive Analytics Dashboard

Project Overview

This end-to-end data pipeline utilizes Python, Scikit-learn, and Power BI to analyze the Bengaluru real estate market. It cleans complex, messy data, predicts property prices using machine learning, and presents the findings in a 3-page interactive business intelligence dashboard.

  • Tech Stack: Python (Pandas, Scikit-learn), Power BI, DAX
  • Data Engineering: Handled missing values, parsed square footage ranges, and grouped rare locations.
  • Machine Learning: Trained a Random Forest Regressor to predict house prices and extract feature importances.
